# CollabSpace — Project Report Template

## Abstract
CollabSpace is a web-based collaborative workspace prototype intended to centralize team chat, tasks, shared code snippets, brainstorming notes, project documents, and AI-assisted help in one interface.

## Problem statement
Disconnected tools create context switching and scatter project knowledge. CollabSpace groups core teamwork features in one workspace.

## Objectives
- Provide a unified dashboard and shared team communication.
- Track tasks, assignees, priorities, and completion status.
- Share code examples, documents, and whiteboard notes.
- Provide an assistant for summaries and programming guidance.
- Demonstrate a Git/GitHub → Maven → Jenkins → Docker → Kubernetes delivery pipeline.

## Technology stack
- Java 17, Spring Boot, Maven
- HTML, CSS, JavaScript
- REST API and WebSocket events
- Docker / Docker Compose
- Jenkins Pipeline
- Kubernetes manifests
